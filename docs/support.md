# Support

If you need help using SpamSniper or want to report a problem, the best way to reach us is through GitHub.

## Report an Issue

Open a GitHub issue in this repository with:

- a short summary of the problem
- the steps to reproduce it
- the device and iOS version you are using
- any relevant screenshots or error messages

## Request Help

For usage questions or feature requests, describe what you want to do and where you got stuck.

## Troubleshooting

- Make sure SpamSniper has the required permissions in Settings.
- If call blocking is not working, verify that the Call Directory extension is enabled and that the app has loaded the latest blocklist data.
- Restart the app after changing repository selections or personal blocklist entries.

## Privacy & Data

SpamSniper does not send your personal phone numbers to a server. It syncs blocklists from trusted repositories and stores personal blocklist entries locally on your device.

## Thank You

Thanks for using SpamSniper! Your feedback helps improve the app and its handling of spam calls.
